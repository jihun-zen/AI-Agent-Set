# 오류 처리

1. 기존 `IExceptionHandler`, 오류 응답 모델, 상태 코드 규칙을 먼저 확인하고 확장합니다.
2. 예상 가능한 입력·도메인 오류는 엔드포인트에서 공통 오류 응답으로 반환하고, 예기치 않은 예외만 전역 처리기로 보냅니다.
3. 내부 예외 상세, 비밀 정보, 요청 본문을 클라이언트 오류 응답에 노출하지 않습니다.
4. JSON 오류 응답은 소스 생성기 컨텍스트를 사용합니다.
5. 취소 요청은 서버 오류로 기록하지 않습니다.
6. 오류 시나리오와 상태 코드 매핑을 테스트하고 AOT 게시에서 트리밍 경고가 없는지 확인합니다.
