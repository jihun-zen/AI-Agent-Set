# 비동기 동시성 제어

1. `SemaphoreSlim.WaitAsync`에 취소 토큰과 필요 시 타임아웃을 전달합니다.
2. 잠금 획득 뒤에는 반드시 `try/finally`에서 `Release`합니다.
3. 잠금 전 검사한 상태는 잠금 내부에서 다시 확인합니다.
4. 잠금 안에서 긴 I/O, 재진입, 다른 잠금의 순환 획득을 피합니다.
5. `SemaphoreSlim`은 프로세스 내부에서만 유효합니다. 다중 인스턴스 작업에는 DB 제약·큐 의미론·분산 잠금 등 인프라 수준 수단을 사용합니다.
6. 락 대기·획득·해제의 정보 로그는 남기지 않고, 타임아웃·예외·실제 상태 변화만 기록합니다.
